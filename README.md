# erkan.dev

The personal website of [Erkan Ercan](https://erkan.dev): software engineer,
product builder, and the person behind [Sablebook](https://sablebook.com) and
[73Kit](https://73kit.erkan.dev).

It is a single-page Next.js site built around one interactive question: what
sits underneath a complicated, stubborn problem? The answer includes project
case files, an X-ray view, a cursor-aware character, and a few Easter eggs.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [localhost:3000](http://localhost:3000).

## Check the build

```bash
pnpm lint
pnpm exec tsc --noEmit
pnpm exec next build --webpack
```

The Webpack flag keeps the production check reliable in restricted local
environments where Turbopack cannot start its CSS worker.

## Search ownership

The site supports optional build-time ownership tokens for webmaster tools:

```bash
GOOGLE_SITE_VERIFICATION=...
BING_SITE_VERIFICATION=...
```

Canonical metadata, the XML sitemap, crawl rules, social cards, and the
ProfilePage/Person/SoftwareApplication structured-data graph are generated by
the app.
